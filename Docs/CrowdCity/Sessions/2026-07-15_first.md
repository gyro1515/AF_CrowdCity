## 2. 설계 단계 (교차검증 4라운드 → 합의)

  더 큰 크라우드가 작은 크라우드를 흡수/제거, 제한시간 내 최다 크라우드 승리.
- CODEX ↔ Claude 교차검증 4라운드를 거쳐 `DESIGN.md`(v4)와 `INTERFACES.md`(파일별 공개 API 핀) 확정.
- 권위 규칙: "공개 시그니처/메서드명/wave 배정이 두 문서에서 다르면 INTERFACES.md가 최종."
- 핵심 아키텍처 합의:
  - **결정론 시뮬레이션 커널**을 순수 C# asmdef(`Project.CrowdCity.Core`)로 분리 + NUnit EditMode 테스트.
  - 고정 스텝(0.02s, 프레임당 ≤4스텝), **스냅샷-순수 전투 해석**(결과가 pair/agent 순서와 무관).
  - 발행 순서 = 모든 count 이벤트 먼저, 그다음 elimination(플레이어 우선) — 동기 dispatch에서 패배 우선순위 보장.
  - **static EventManager** 사용(EventBus GetPublisher/GetSubscriber + QueryBus + ClearAll + RuntimeInitializeOnLoad).
  - SO 소비자 불변성, 프리팹 기반 생성, Destroy 없으므로 풀링 미도입.

## 4. 진행 중 발생한 문제와 수정 (하나도 빠짐없이)

1. **EventManager API 오보고**: 최초 조사 에이전트가 instance 기반으로 잘못 보고 →
   실제 파일 확인 결과 static API. 이로 인해 설계 전체를 static API로 재작성.
2. **GameConfigSO SO 원칙 위반**: public mutable 필드 노출. 사용자 지적 "이걸 가져가는 곳은 상수여야지" →
   `[SerializeField] private` + get-only 프로퍼티로 수정.
3. **IDE 네이밍 진단**: `[SerializeField]` 필드에 `_` 접두사 → 프로젝트 규칙 위반(직렬화 필드는 언더스코어 없는 camelCase) →
   언더스코어 제거. (메모리 `so-consumer-immutability.md`에 규칙 기록.)
4. **CODEX MAJOR — IReadOnlyList 다운캐스트 변조 가능**: `IReadOnlyList<T>`를 `T[]`로 캐스팅해 요소 변조 가능 →
   캐시된 `ReadOnlyCollection<T>`(Array.AsReadOnly)로 노출해 차단.
5. **EventManager 인프라 손상 발견(git)**: asmdef + Tests 삭제, EventManager.cs 수정 상태.
   AskUserQuestion으로 사용자 결정: **"static 유지, 현 상태 그대로"** (복원 안 함). 테스트 게이트에서 EventManager suite 요구 제거.
6. **시각 버그 — 도시/중립 안 보이고 회색 위 크라우드만**: 원인은 카메라가 아니라 **리더가 맵을 벗어남**.
   `MoveLeaders`가 리더 X/Z를 walkable region으로 clamp하지 않아 리더가 (234,238)까지 탈출 → 추종 카메라가 도시를 벗어남.
   `CrowdRoot.MoveLeaders`에 중립과 동일한 clamp 추가로 수정(diag_after.png로 전체 도시 확인).
7. **워크플로 세션 한도 2회**: Anthropic 쿼터로 실패 → `resumeFromRunId`로 재개.
8. **에디터 포커스 이슈**: unity-cli headless play는 `Application.runInBackground=true`가 아니면 프레임 미진행.
   런타임에서 설정(파일 수정 아님). 실제 게임 버그 아님. 단, 도메인 리로드 후 재설정 필요(스모크 절차에 반영).
9. **HUD 스크린샷 캡처 한계**: screen-space uGUI가 game-view 캡처에 합성 안 됨(커넥터 특성).
   exec로 8/8 Text active 확인. 게이팅 실패 아님.

## 5. 최종 교차검증 (구현 완료 후) — 합의까지

시니어 Unity 프로그래머 관점으로 CODEX와 Claude가 각각 전체 구현 독립 리뷰.

### 1차 결과

- **Claude 최종 리뷰: VERDICT APPROVE** — 미해결 BLOCKER/MAJOR 0. (결정론/스냅샷 순수성/elimination 귀속/
  발행순서/패배 우선/재시작 누수/무할당 등 직접 검증). MINOR 5건(팔로워 슬롯 index churn, RivalAi 경계 인지,
  HUD ToString 할당, EventManager GetInvocationList 편집 경로 할당[off-limits], CrowdRoot:350 중복 Clear).
- **CODEX 최종 리뷰: VERDICT REVISE** — MAJOR 1 + MINOR 10:
  1. [MAJOR] CrowdRoot 팔로워가 맵을 벗어남 — golden-angle 슬롯이 리더 밖으로 퍼지는데 clamp 없음 → 맵 밖 recruit/전투
  2~11. [MINOR] RecruitResolver 스크래치 리사이즈, CrowdModel 병렬리스트 캡슐화, Ground 최소크기 가드,
     CombatResolver 팀ID 범위, MatchRules 배열길이, SpatialGrid 극단반경, 에디터 collider 재귀정리,
     Validator 카메라 동일성, Validator prefab.activeSelf, prefab 불필요 재기록

### 병합 판정 (매니저)

합의 차단 요인은 팔로워 clamp(MAJOR) 하나. 아래만 반영하면 합의 도달, 나머지 MINOR는 근거와 함께 수용·보류.

### 반영한 수정 (파일 소유자 서브에이전트에 위임, 구현/검증 분리)

1. **(MAJOR)** `CrowdRoot.SteerFollowersAndNeutrals` — 팔로워 커밋 위치를
   `Mathf.Clamp(_regionMin/Max X/Z)`로 clamp(리더/중립과 동일 패턴). 중복 Clear 제거도 동반.
2. `RecruitResolver.Resolve` — `_candidates.Capacity`를 첫 tick에 `buffer.Id.Length`로 1회 확장(핫패스 재할당 제거).
3. `CrowdRoot` — `CombatResolver.Resolve` 직전 중복 `_combatOutcome.Clear()` 제거.

### 검증 (구현과 분리된 검증 에이전트)

- **핵심 정합성**: 팔로워 clamp가 프레젠테이션 전용이 아니라 **AgentBuffer까지 전파**됨을 확인.
  경로: transform(SetPosition, clamp됨) → `MirrorPositionsToBuffer`(SimTick step ⑤) → `_buffer.Pos` → recruit(⑦)/combat(⑧).
  `_buffer.Pos` per-tick writer는 미러링 1곳뿐 → unclamped 값이 버퍼에 도달 불가.
- **런타임 프로브**(~5s, 154 agents): region X[-46.4,46.4] Z[-45.7,45.7], 관측 전부 내부, **OUTSIDE=0**.
- 컴파일 **0 에러/0 경고**, **EditMode 28 pass / 0 fail**(RecruitResolver/CombatResolver 결정론 유지),
  씬 셋업+검증 통과, play-smoke 스크린샷 크라우드 도시 내부(`Screenshots/smoke_edges.png`).

### CODEX 재리뷰 → 합의 확정

변경분 한정 재리뷰 결과 **VERDICT APPROVE**, 3개 수정 모두 **RESOLVED**.

| 리뷰 | 판정 |

| Claude 최종 | APPROVE |
| CODEX 최종 | REVISE (MAJOR 1 + MINOR 10) |
| 수정 반영 후 CODEX 재리뷰 | APPROVE (3건 RESOLVED) |

## 6. 수용·보류한 MINOR (근거)

MVP 범위에서 의도적으로 보류. 필요 시 후속 태스크.

- CrowdModel 병렬 리스트 캡슐화 — 유일 mutator=소유자(CrowdRoot), 외부 참조 없음(이론적 위험).
- CombatResolver 팀ID / MatchRules 배열길이 방어 검증 — 내부 호출자만 존재, 도달 불가 시나리오(§Simplicity First).
- SpatialGrid 극단 반경 / Ground 최소크기 가드 — 고정 config·고정 도시라 실사용 도달 불가.
- 에디터 위생(collider 재귀정리, Validator 카메라 동일성/prefab.activeSelf, 불필요 prefab 재기록) — 에디터 전용 도구.
- RivalAiDriver 경계 인지 — 중립 밀도 벡터로 자기보정(플레이상 문제 미관측).
- HudRoot per-event `ToString()` 할당 — 프레젠테이션 경로, 양측 MVP 허용.
- EventManager `GetInvocationList()` 편집 경로 할당 — **off-limits 정본 인프라, 편집 금지**.
